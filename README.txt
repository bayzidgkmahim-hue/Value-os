RAGE MODE - APK build (phone only)
1. Create a new GitHub repo (github.com, works in a mobile browser).
2. Upload ALL files from this zip, keeping folders (www/, .github/workflows/).
3. Repo > Actions > "Build APK" > Run workflow (about 5-8 min).
4. Open the finished run > Artifacts > rage-mode-apk. Unzip, tap app-debug.apk, allow "install unknown apps".
Alt (PWA): host the www/ folder on Netlify/GitHub Pages, open it in Chrome > menu > Install app.
